# family-age-tracker

Petit site statique (Vite + TypeScript) pour afficher l'âge en années/mois/jours.

## Configuration des dates de naissance

Modifie le fichier `src/config.ts` et adapte le tableau `familyMembers`.

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
